# Tư Duy Đúng – Book App V2.5

V2.5 tích hợp toàn bộ nền tảng các bản trước và bổ sung chế độ học tương tác.

## Nội dung và tính năng
- 10 phần / 40 bài học sâu.
- Mỗi bài giữ đủ: Khái niệm, Cách áp dụng, Tại sao quan trọng, Sai lầm thường gặp, Ví dụ thực tế, Checklist, Bài tập áp dụng, Câu hỏi tự phản tư.
- Sơ đồ ghi nhớ nhiều dạng: flow, steps, matrix, compare, ladder, cycle.
- Tìm kiếm, bookmark, đánh dấu đã đọc, tăng/giảm cỡ chữ, lưu tiến độ.
- Cuộn chuột/touchpad được định tuyến theo vùng con trỏ.
- Learning Mode: quiz cho đủ 40 bài, lưu điểm cao nhất.
- Case Study Mode: 8 tình huống thực tế có lựa chọn và giải thích.
- Thinking & Management Tools: 15 công cụ thực hành.
- Từ điển tích hợp 40 thuật ngữ.
- Dashboard tiến độ đọc, quiz và case study.
- Giữ dữ liệu cũ tại %APPDATA%\TuDuyDungBookApp\state.json.
- EXE portable, không mở CMD.

## Kiểm tra trước build
GitHub Actions bắt buộc chạy:
1. Python syntax check.
2. Validate đủ 10 chương / 40 bài và schema nội dung.
3. Validate Quiz / Case / Tools / Glossary.
4. GUI smoke test trên Windows.
5. Build EXE và xác nhận file tồn tại, dung lượng hợp lý.

Tên EXE: TuDuyDung_BookApp_V2.5.exe
